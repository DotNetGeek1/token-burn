# Downloads

Place the Android playtest build here as `token-burn.apk`. The download page links to
`/downloads/token-burn.apk`; to host the APK elsewhere instead, change `apkHref` in
[`src/lib/site.ts`](../../src/lib/site.ts) to the external URL.

APKs are not committed to this repo — upload the file as part of the deploy or attach it to a
GitHub release and point `apkHref` at that URL.

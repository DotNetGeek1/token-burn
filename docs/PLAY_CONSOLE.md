# Play Console and closed test (#45)

This is a **personal** developer account created after 13 November 2023. Google requires a **closed test with at least 12 opted-in testers for 14 continuous days** before you can apply for production.

Start this as soon as the first signed AAB exists (end of Phase 2). Updates to the closed track **do not reset the clock** if testers stay opted in.

## User-owned steps

1. Create the app record: **Token Burn**, package `com.tokenburn.game`
2. Enable Play App Signing
3. Create a closed testing track
4. Upload the signed AAB from [ANDROID_RELEASE.md](ANDROID_RELEASE.md)
5. Recruit 12 testers (friends, colleagues). They must **opt in** via the track link, not merely be listed
6. Confirm Play Console shows 12+ opted-in testers
7. Leave the track live for 14 days
8. Then apply for production access

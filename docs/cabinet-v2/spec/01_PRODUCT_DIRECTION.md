# 01 — Product direction

## Decision

Token Burn no longer progresses through Bedroom → Garage → Office → Warehouse → Data Centre → Power Grid → Moon Facility.

The Burn Cabinet is now the setting, the workstation and the visual progression fantasy. The player starts with an unsafe improvised machine and ends with an impossible token engine.

The game loop stays on the cabinet:

`Choose contract → shape workflow → buy modules/perks/systems → preview consequence → commit → burn → settle round`

## Player-facing hierarchy

1. **Modules and perks** are the run-defining choices.
2. **Five cabinet systems** provide capacity and infrastructure.
3. **Cabinet evolution** visibly reflects those system tiers; it is not bought separately.
4. **Meta unlocks** expand what can appear in later runs.

There is no property shop, room economy, furniture placement or travel between venues.

## The five cabinet systems

- Compute Stack — base throughput.
- Cooling Loop — thermal capacity and recovery.
- Power Bus — hardware headroom and risky boost support.
- Workflow Backplane — workflow/module bay capacity.
- Control Rack — number of saved workflows.

These are deliberately not called modules. “Module” continues to mean a workflow cartridge.

## Camera model

- **Operation view:** close, readable cabinet gameplay. This is the default and contains the full run loop.
- **Maintenance view:** zoomed-out inspection/pause shell showing the entire evolving machine. It contains Resume, Settings, Help, Records/Achievements and Save & Quit.

Maintenance is not a second management layer. System purchases happen in the Market/Systems tab, followed by a brief zoom-out installation reveal.

## Visual generations

The machine may be described with five derived visual generations:

1. Improvised Cabinet
2. Spliced Rig
3. Token Furnace
4. Grid Eater
5. Impossible Engine

The generation is derived from system progress. The player never buys “Cabinet Level 3”.

## What must remain true

- Contracts, market, modules, perks and run/burn remain CRT tabs.
- Existing simulation rules, economy and round flow remain authoritative unless explicitly replaced by the system migration phase.
- The cabinet feels tactile: select digitally, commit physically.
- Landscape mobile is a first-class target, not a desktop layout scaled down.
